Cómo escribir fórmulas matemáticas

Tutorial para el contenido educativo del Proyecto de Física

1. Dónde se escriben las fórmulas

El proyecto usa KaTeX para convertir expresiones escritas con sintaxis LaTeX en fórmulas renderizadas en el navegador. El contenido se escribe en:

  • src/assets/topicDetails.js: teoría y explicaciones.
  • src/assets/exercisesData.js: enunciados y soluciones.

Las fórmulas se colocan dentro de las cadenas content, enunciado o solucion. No es necesario modificar los componentes de Vue para agregar una expresión.

2. Delimitadores

Fórmula en línea: $...$

Se usa cuando la fórmula forma parte de un párrafo:

enunciado: `
La segunda ley de Newton se expresa como $F = ma$.
`,

Resultado: F = ma

Fórmula independiente: $$...$$

Se usa para ecuaciones que deben destacarse o centrarse:

solucion: `
<p>Aplicamos la segunda ley de Newton:</p>
$$ F = ma $$
`,

F = ma

Regla práctica: usa $...$ para símbolos breves dentro de una oración y $$...$$ para pasos de cálculo o ecuaciones importantes.

3. Escapar las barras en JavaScript

Los contenidos están dentro de cadenas JavaScript. Por eso, cada comando LaTeX que comienza con una barra inversa debe escribirse con dos barras inversas:

solucion: `
$$ W = Fd\\cos(\\theta) $$
`,

KaTeX recibe finalmente W = Fd\cos(\theta).

\frac{a}{b}\\frac{a}{b}
\sqrt{x}\\sqrt{x}
\theta\\theta
\text{metros}\\text{metros}
\cdot\\cdot

4. Sintaxis LaTeX útil para Física

$$ v = \\frac{\\Delta x}{\\Delta t} $$
$$ E_c = \\frac{1}{2}mv^2 $$
$$ v_x = v\\cos(\\theta) $$
$$ a = \\sqrt{a_x^2 + a_y^2} $$
$$ F = 12\\,\\text{N} $$

v = Δx/Δt     Ec = ½mv²     vx = v cos(θ)

\\sqrt{...} crea raíces, \\, agrega espacio antes de una unidad, \\text{...} escribe texto normal y \\cdot muestra un punto de multiplicación.

Letras griegas, vectores y sistemas

$\\alpha$, $\\beta$, $\\theta$, $\\Delta x$
$$ \\vec{F} = m\\vec{a} $$
$$ \\mathbf{v} = (v_x, v_y) $$

Para varias líneas, usa aligned y recuerda escapar los saltos de línea:

$$
\\begin{aligned}
\\sum F_x &= ma_x \\\\
\\sum F_y &= ma_y
\\end{aligned}
$$

5. Combinar HTML y fórmulas

El contenido admite HTML sencillo para explicar cada paso y colocar la fórmula debajo:

solucion: `
<p>El trabajo de una fuerza constante es:</p>
$$ W = Fd\\cos(\\theta) $$
<p>Si tienen la misma dirección:</p>
$$ W = Fd $$
`,

Mantén el HTML bien formado y coloca cada ecuación independiente entre sus propios delimitadores.

6. Ejemplo completo de un ejercicio

{
  enunciado: `
    <p>Un objeto de masa $m = 2\\,\\text{kg}$ se mueve con
    aceleración $a = 3\\,\\text{m/s}^2$. ¿Cuál es la fuerza neta?</p>
  `,
  solucion: `
    <p>Aplicamos la segunda ley de Newton:</p>
    $$ F = ma $$
    <p>Sustituyendo los valores:</p>
    $$ F = (2\\,\\text{kg})(3\\,\\text{m/s}^2) = 6\\,\\text{N} $$
  `,
},

7. Cómo comprobar una fórmula

  1. Ejecuta npm run dev.
  2. Abre el tema o ejercicio que contiene la fórmula.
  3. Comprueba subíndices, exponentes, fracciones y símbolos.
  4. Si aparece texto plano, revisa los delimitadores $ y $$.
  5. Si faltan símbolos, revisa las barras duplicadas en el archivo JavaScript.
  6. Para ecuaciones largas, revisa las llaves y los paréntesis.

La vista de ejercicios usa throwOnError: false. Cuando KaTeX no interpreta una expresión, conserva el texto problemático y registra el error en la consola del navegador.

8. Errores frecuentes

Incorrecto: $$ \frac{1}{2}mv^2 $$

Correcto: $$ \\frac{1}{2}mv^2 $$

Cada $ debe tener su pareja y cada $$ debe cerrarse con otro $$. Para unidades usa \\text{N}, no HTML dentro de la fórmula.

9. Resumen rápido

  • Contenido: topicDetails.js o exercisesData.js.
  • En línea: $...$. Independiente: $$...$$.
  • Comandos LaTeX en JavaScript: \\frac, \\sqrt, \\theta.
  • Texto y unidades: \\text{...}.
  • Validación: npm run dev.
